# 唇语输入法 MVP PRD

**版本**：MVP v0.1
**状态**：进入实现
**最后更新**：2026-10-11

## 1. 本次 MVP 要验证什么

本次 MVP 不负责证明中文唇语识别已经足够准确，也不负责替换系统输入法。它只验证一个最小产品闭环：

> 用户在电脑前按住快捷键、无声地做出说话动作，松开快捷键后，系统能够完成一次中文唇语识别，并把结果复制到剪贴板。

固定视频 Prototype 已经证明“预处理 → 模型推理 → 中文文本输出”可以在本机运行；本次把输入方式从“手机录视频并传到电脑”推进到“电脑摄像头 + 快捷键”。

## 2. 目标用户与场景

- **第一用户**：项目发起人本人。
- **核心场景**：教室、图书馆、办公室等不能或不方便出声、但用户仍坐在电脑前的场合。
- **拍摄约束**：单人、正面、稳定光线、嘴部无遮挡。
- **输出对象**：用户当前需要复制到其他应用中的中文文本。

## 3. MVP 用户流

```text
启动应用
  → 常驻后台进程（摄像头保持关闭）
  → 首次运行显示 setup / 模型加载 HUD
  → 按住 F9
  → 启动摄像头并检测嘴部
  → 底部 HUD：嘴部关键点、LISTENING 和临时识别
  → 松开 F9
  → 继续保留约 0.4 秒尾帧
  → 关闭摄像头
  → Reading your lips：完成最终识别
  → 结果显示并复制到剪贴板
```

## 4. In scope

- 启动后保持后台常驻，不自动打开摄像头，不创建大摄像头窗口。
- 首次运行显示 setup 引导和底部 loading/ready HUD；setup 当前不声称完成个性化模型训练。
- 按住 F9 后才打开 Windows 摄像头。
- 使用已验证的 CNVSRC2025 中文视觉语音识别模型。
- RetinaFace/FAN 人脸与关键点检测。
- 裁剪嘴唇主体及少量周边，并固定显示在屏幕底部中央 HUD 的左侧。
- HUD 右侧上方显示 `LISTENING` / `READING YOUR LIPS`，下方显示实时识别效果。
- F9 按下/松开控制一段输入。
- 松开 F9 后默认继续采集约 0.4 秒尾帧，避免截断最后一个词的嘴型。
- 25 FPS 模型输入重采样。
- 识别状态显示：`READY`、`RECORDING`、`READING YOUR LIPS`。
- 识别结果复制到系统剪贴板。
- 本地记录识别文本、延迟和模型帧数。

## 5. Out of scope

- 系统级输入法注册。
- 自动向任意输入框粘贴。
- 多人画面、侧脸、遮挡、拥挤环境和复杂光线。
- 麦克风、音视频融合或耳语模式。
- 外部 LLM 改写、总结和语义补全。
- 重新训练中文模型。
- 识别准确率承诺或“可日常使用”结论。

## 6. 功能需求

| ID | 需求 | 验收方式 |
| --- | --- | --- |
| F-01 | 应用启动后保持常驻且不打开摄像头 | 没有大摄像头窗口，摄像头未被占用 |
| F-02 | 首次启动显示 setup，模型加载显示底部 HUD | setup 可关闭，HUD 可显示 loading / ready |
| F-03 | 按住 F9 后打开默认摄像头并找到嘴部 | 底部 HUD 出现嘴部裁剪和关键点 |
| F-04 | 录制时显示嘴唇窗口、录制提示和实时识别 | HUD 同时显示三者 |
| F-05 | 录制过程中不保存音频 | 输入链路只使用画面帧 |
| F-06 | 松开 F9 后保留尾帧，再关闭摄像头并进入识别状态 | HUD 变为 `READING YOUR LIPS`，嘴部视频隐藏 |
| F-07 | 完成一次最终中文推理 | HUD 显示结果或明确错误 |
| F-08 | 结果进入剪贴板 | 在记事本中可以 `Ctrl+V` 粘贴 |
| F-09 | 记录延迟和失败原因 | `outputs/mvp/recognitions.jsonl` 有记录 |

## 7. 性能与质量边界

- 摄像头采集和嘴部框优先保持响应；实时文字预览默认约每 0.45 秒更新一次，允许延迟。
- CPU 推理下，松键后等待数秒属于预期，不把“实时”解释成逐帧即时识别。
- 松键后的 0.4 秒是采集尾帧，不代表模型在这段时间内已经完成识别。
- 最终识别沿用现有模型输出，不接入语义大模型，避免把模型能力和后处理能力混在一起。
- 识别准确率作为独立指标记录，不作为本轮交互闭环的阻塞条件。

## 8. 失败状态

- 摄像头打不开：提示检查 Windows 摄像头权限或切换摄像头编号。
- 没检测到人脸：提示正对摄像头并保持嘴部可见。
- 帧数过少：提示按住快捷键更久。
- 模型推理失败：保留错误类型，不复制空结果。
- 用户按 Esc：退出应用并释放摄像头。

## 9. 当前实现边界

第一版实现采用隐藏根窗口、底部非抢焦点 HUD、后台摄像头线程和全局 F9 监听，不做安装包、不做系统级输入法。代码提供实验性 `--paste` 选项，但默认仍只复制到剪贴板；setup 当前只完成引导，不代表个人化训练已经实现。
