# 开源与试用准备

## 当前可交付范围

- GitHub 远端 `Maki3991/move-your-lips` 已是公开仓库。本轮选择先发布源码研究版；推送状态以 GitHub 上实际提交为准。
- 项目源码包含通用的 24 句采集、18 句训练、6 句留出比较，以及手动选用或恢复模型。每位使用者的数据保存在各自的 `outputs/mvp/`。
- 当前交付形式是 Windows 源码项目，依赖 Python、上游 CNVSRC2025 代码、检测模块和模型权重。还没有经过外部电脑验证的安装包，不宜在朋友圈称为“下载后直接使用”。
- 录制历史、嘴部 MP4、无损采集样本、个人候选 checkpoint、虚拟环境、本机设置和上游代码/权重均被 `.gitignore` 排除。发布前仍需人工检查将要提交的文件清单。

## 已做的发布选择

1. **本项目源码许可证：MIT。** 根目录 `LICENSE` 覆盖本项目自有代码和文档；第三方资源见 `THIRD_PARTY.md`。
2. **第一版交付：源码研究版。** 面向愿意手动安装依赖的人。如果要让普通朋友下载后直接使用，需要另做 Windows 打包、外部电脑安装验证及模型获取流程。

CNVSRC2025 的 [README](https://github.com/liu12366262626/CNVSRC2025/blob/main/VSR/README.md) 明确写有非商业比较或基准测试用途限制；[LICENSE](https://github.com/liu12366262626/CNVSRC2025/blob/main/VSR/LICENSE) 还包含个人研究、私下学习等条款。项目 README 应提示用户自行阅读并遵守。上游权重和代码不打包进入本仓库；若以后要作为面向公众日常使用的应用分发，需先核实或取得相应授权。
可选 CMLR 项目的 [README](https://github.com/mpc001/Visual_Speech_Recognition_for_Multiple_Languages#license) 也限定非商业比较或基准测试用途。

## 对外描述建议

“这是一个本地运行的中文纯视觉唇语输入研究原型。已有个人适配实验，效果有改善但准确率仍不足以当作可靠输入法。当前公开源码，模型需按上游要求自行安装。欢迎愿意测试的朋友反馈设备、使用场景和识别结果。”
