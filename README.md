# 唇语输入法（Move Your Lips）

一个面向中文用户的本地优先桌面原型，目标是在不能出声的公共场合，让用户通过无声的说话动作生成可编辑中文文本。

## 当前状态

项目当前进入 Prototype v0.1 定义与验证准备阶段。当前只保存已经做出的产品判断、问题定义过程和证据记录；尚未声称中文唇语输入已经可用，也尚未完成模型复现或真实摄像头验收。

当前已经冻结第一版 Prototype 的最小范围：先选择一段固定的、由本人录制的无声普通话视频，验证公开中文视觉语音模型能否在本机完成：

```text
本地视频文件 -> 人脸/嘴部区域 -> 中文视觉语音识别 -> 可读文本
```

如果这条链路成立，再进入实时摄像头、开始/结束方式和文本输入功能的设计。

## 当前阶段

当前处于：

```text
问题定义 -> POV -> HMW -> Prototype v0.1 验证
```

当前暂不建立完整 PRD。等固定视频识别原型完成并决定进入实时摄像头 MVP 后，再把稳定的用户流、功能需求和验收标准整理成 PRD。

## Prototype v0.1 边界

第一版只做：

- 选择一段固定视频；
- 读取单人、正面、稳定光线的无声普通话视频；
- 识别为简体中文文本；
- 显示识别结果；
- 对照标准答案记录识别效果。

第一版暂不做：

- 实时摄像头；
- Alt 快捷键；
- 输入框自动填充；
- 系统级输入法；
- AI 润色、总结或改写；
- 多人和拥挤环境。

## 重要边界

- “中文数据集上的 CER”不等于“对着普通电脑摄像头连续输入中文可用”。
- 摄像头本身仍会采集脸部画面；“不使用麦克风”和“完全没有隐私风险”不是同一件事。
- 上游模型、数据集和权重的许可证需要单独核对；开源自己的适配代码不自动授予上游权重或数据的再分发权。
- GitHub 仓库、可运行 Demo、用户验证和商业可用性是四个不同的完成状态。
