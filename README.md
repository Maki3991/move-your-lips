# 唇语输入法（Move Your Lips）

一个面向中文用户的本地优先桌面原型，目标是在不能出声的公共场合，让用户通过无声的说话动作生成可编辑中文文本。

## 当前状态

项目已完成 MVP v0.1 的实时交互闭环，并于 2026-10-12 进入 MVP v0.2 迭代。固定视频 Prototype 已完成技术验证并保留为历史基线；CNVSRC2025 的识别质量仍未达到“可用中文唇语输入”标准，实时使用中的识别结果目前被用户评价为几乎不可用，具体原因和改善空间需要通过新的受控基线实验确认。

固定视频阶段验证了公开中文视觉语音模型能否在本机完成：

```text
本地视频文件 -> 人脸/嘴部区域 -> 中文视觉语音识别 -> 可读文本
```

这条链路已经跑通，但手动录制、传输和识别与原始使用场景不一致。因此当前转入实时 MVP：

```text
常驻后台进程（摄像头关闭） -> 底部 HUD / setup
-> 按住 Right Ctrl -> 底部嘴部 HUD + 实时文字
-> 松开后保留 0.4 秒尾帧 -> Reading your lips -> 复制中文结果
-> Home 历史记录刷新（可选：粘贴到当前输入框）
```

当前已完成一次技术冒烟测试：全脸视频经过 RetinaFace/FAN 预处理，并将 30 FPS 画面真正重采样为 25 FPS 的 96×96 嘴部视频；CNVSRC2025 在 CPU 上完成推理。与已确认的标准答案对照后，CER 为 29.41%，仍未达到本项目“可用中文草稿”的验收要求。详见 [Evidence](docs/evidence.md)。

## 当前阶段

当前状态为：

```text
问题定义 -> POV -> HMW -> Prototype v0.1 固定视频验证 -> MVP v0.1 实时交互实现 -> MVP v0.2 迭代验证
```

固定视频 Prototype 的技术结果已经归档，不代表删除：原始视频、预处理结果、模型输出和实验记录仍保留在 `test-results/` 与 `docs/evidence.md`。

实时 MVP 的用户流、功能需求、异常状态和验收标准已整理在 [MVP PRD](docs/mvp-prd.md)。当前 PRD 描述 MVP v0.2；它不代表系统级输入法、模型准确率或商业可用性已经完成。

## Prototype v0.1 边界（已完成的历史阶段）

第一版只做：

- 选择一段固定视频；
- 读取单人、正面、稳定光线的无声普通话视频；
- 识别为简体中文文本；
- 显示识别结果；
- 对照标准答案记录识别效果。

本阶段暂不做：

- 实时摄像头；
- Alt 快捷键；
- 输入框自动填充；
- 系统级输入法；
- AI 润色、总结或改写；
- 多人和拥挤环境。

## MVP v0.1 边界（已完成基线）

当前先做最小可用闭环：

- 启动后保持常驻，不创建大摄像头窗口；首次运行显示 setup，模型加载和状态通过底部 HUD 提示；
- 按住 Right Ctrl 后才打开本地摄像头，并在屏幕底部中央显示带关键点的嘴部 HUD；
- 按住 Right Ctrl 开始录制，松开结束；
- 松开后默认保留约 0.4 秒尾帧，再进入最终识别；
- HUD 左侧显示嘴部裁剪和关键点，右侧显示录制状态及实时识别结果；
- 调用现有 CNVSRC2025 模型完成最终识别；
- 将结果复制到剪贴板，并记录本地运行结果。

当前仍不做：

- 自动粘贴到任意输入框或系统级输入法；
- 麦克风、音频识别、外部 LLM 润色；
- 多人、侧脸、遮挡、拥挤背景和准确率承诺。

开发者曾用 `--paste` 做 Lipflow 风格的当前窗口粘贴实验；默认启动脚本不启用该选项，仍只复制到剪贴板。setup 当前只完成使用引导，个性化训练尚未接入。

## MVP v0.2 范围（当前迭代）

### 产品体验线

- Home 页面继续作为本地历史入口，识别过程中与底部 HUD 独立显示；
- 识别完成后自动刷新历史记录，并支持通过文件变化或 `Ctrl+R` 手动刷新；
- 每条历史记录支持再次复制，并可从 Home 页面打开本地存储文件夹；
- 增加显式开启的直接输入/当前窗口粘贴，默认仍保持复制到剪贴板；
- 保留失败提示、取消和重试路径，不把错误识别静默写入输入框。

### 模型诊断线

- 建立至少 10 句话 × 3 次的带标准答案测试集；
- 对比固定视频离线识别、实时录制后离线识别、实时最终识别；
- 记录 CER、整句正确率、有效帧数、失败原因和耗时；
- 只有候选模型或个人适配在未见测试句上优于当前基线时，才考虑替换默认模型；
- 个人微调、24 句校准和新模型接入都属于实验，不承诺必然改善。

MVP v0.2 暂不做：系统级输入法、默认自动粘贴、音频保存、外部 LLM 润色、多人场景和准确率承诺。

## Home / HUD 本地界面

Home 页面和底部状态 HUD 使用 PySide6 + QML；摄像头采集、识别和历史记录仍由 Python 逻辑处理。首次运行前，在启动脚本使用的 Python 环境中安装界面依赖，然后用现有启动脚本运行：

```powershell
D:\cnvsrc-env\python.exe -m pip install -r requirements-ui.txt
.\scripts\run_lip_input_mvp.ps1
```

启动后先显示“正在加载识别模型”；模型就绪后打开 Home。Home 默认以约 `1000×650` 的紧凑尺寸打开，可拖动右下角调整窗口大小，也可以用 `Ctrl +` / `Ctrl -` 调整、`Ctrl + 0` 恢复默认尺寸。按住右 Ctrl 开始录制，松开后进入识别，结果会复制到剪贴板并写入本地历史。鼠标悬停历史卡片可复制或删除（删除前会确认）；关闭/最小化 Home 只会隐藏窗口，Windows 任务栏通知区域会保留 Move Your Lips 图标，点击图标或右键选择“显示 Home”即可重新打开；只有托盘菜单的“退出 Move Your Lips”或启动它的终端 `Ctrl+C` 才会结束常驻程序。

## 重要边界

- “中文数据集上的 CER”不等于“对着普通电脑摄像头连续输入中文可用”。
- 摄像头本身仍会采集脸部画面；“不使用麦克风”和“完全没有隐私风险”不是同一件事。
- 上游模型、数据集和权重的许可证需要单独核对；开源自己的适配代码不自动授予上游权重或数据的再分发权。
- GitHub 仓库、可运行 Demo、用户验证和商业可用性是四个不同的完成状态。
